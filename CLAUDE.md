## Commands

```bash
bun run dev          # Start dev server (port 3000)
bun run build        # Production build → dist/
bun run start        # Run production server (server.ts)
bun run lint         # ESLint
bun run lint:fix     # Fix ESLint violations
bun run format       # Prettier
bun run db:push      # Sync Drizzle schema with PostgreSQL
```

There are no tests configured (`test` script exits with error).

## Architecture

**Stack**: React 19 + TanStack React Start (SSR) + TanStack Router (file-based) + React Query + Drizzle ORM + PostgreSQL + Better Auth + Tailwind CSS 4 + Bun runtime.

**Data flow**: Route components → `useQuery`/`useMutation` → Server Functions (`src/actions/`) → Drizzle ORM → PostgreSQL. Server functions also make HTTP calls to an external ARCA Scrapper service (`SCRAPPER_JOBS_URL`).

### Key directories

- `src/routes/` — File-based routes. `__root.tsx` is the app shell. `_authed/route.tsx` is the auth-guarded layout (all child routes require a session). Public routes: `/login`, `/api/auth/*`.
- `src/actions/` — All backend logic as `createServerFn()` handlers. Auth check via `auth.api.getSession()` is required in every handler.
- `src/components/ui/` — Radix UI primitives (shadcn-style). Use these for all UI primitives.
- `drizzle/schema.ts` — Main DB schema. `drizzle/auth.ts` — Better Auth tables.
- `lib/auth.tsx` — Better Auth server config. `lib/auth-client.ts` — client-side auth. `lib/db.ts` — Drizzle client.
- `src/routeTree.gen.ts` — **Auto-generated by TanStack Router, never edit manually.**

### Server Functions pattern

```typescript
// src/actions/feature.tsx
export const getFeature = createServerFn({ method: "GET" })
  .handler(async () => {
    const session = await auth.api.getSession({ headers: getRequestHeaders() });
    if (!session?.user?.id) throw new Error("Unauthorized");
    return await db.select().from(featureTable).where(eq(featureTable.userId, session.user.id));
  });

// With input validation
export const createFeature = createServerFn({ method: "POST" })
  .inputValidator(z.object({ name: z.string() }))
  .handler(async (ctx) => { ... });
```

### Adding a new route/feature

1. Create `src/routes/_authed/feature/index.tsx` with `export const Route = createFileRoute("/_authed/feature/")({ component: ... })`
2. Create `src/actions/feature.tsx` with server functions (always auth-check first)
3. Use `useQuery`/`useMutation` in components to call server functions
4. Invalidate query keys after mutations: `queryClient.invalidateQueries({ queryKey: ["feature"] })`

### External integrations

- **ARCA Scrapper**: Jobs dispatched via `POST ${SCRAPPER_JOBS_URL}/api/jobs`. Configured by `SCRAPPER_JOBS_URL` env var (fallback: `BACKEND_API_URL`, then `http://localhost:3002`). Job types: `iva`, `comprobantes`, `comprobantes_full`, `notificaciones`, `deuda`.
- **AI features**: Google Gemini (`GEMINI_API_KEY`) for PDF scanning in `src/actions/scannerAi.tsx`.

## Conventions

- **Path alias**: `@/` maps to `src/` (also `@/lib/`, `@/drizzle/` for those dirs).
- **Styling**: Tailwind utility classes. Never inline styles. Custom tokens defined in `tailwind.config.mjs`.
- **Icons**: Lucide React only.
- **Notifications/toasts**: Sonner (`import { toast } from "sonner"`).
- **Forms**: React Hook Form + Zod validators via `@hookform/resolvers/zod`.
- **DB access**: Only inside `src/actions/` server functions. Always filter by `userId` for multi-tenancy.
- **ESLint**: TypeScript strict mode. Run `bun run lint:fix` before committing.
