ANÁLISIS: Formato conceptosLSD — Conversión SOS Contador ↔ ARCA
================================================================
Fecha: 27/03/2026
Fuente: archivos conceptosLSD-Epresis.txt y conceptosLSD-Zahrah.txt


1. ESTRUCTURA DEL ARCHIVO LSD
==============================

Cada línea es un registro de ancho fijo con tres partes:

  [Cód ARCA 6 dígitos][Cód contribuyente 10 dígitos][Descripción ancho fijo][Flags subsistemas]

Ejemplo:
  1100000000000001Sueldo Basico ...   11111111111 1 1 10 0
  ^^^^^^ ^^^^^^^^^^ ^^^^^^^^^^^^      ^^^^^^^^^^^^^^^^^^^^
  ARCA   Contribuy.  Descripción      Bases Imponibles (BIs)


2. FLAGS DE BASES IMPONIBLES
=============================

Los flags son fijos por rango de código ARCA. No son configurables por empresa.

  Remunerativo pleno (110xxx, 151xxx, 160xxx, 161xxx, 170xxx):
    Flags: 11111111111 1 1 10 0
    → Activa todas las BIs: SIPA, INSSJyP, OS, FSR, RENATEA, AAFF, FNE, LRT

  No remunerativo con aportes y contribuciones OS (540xxx, 541xxx):
    Flags: 10000111100 0 0 00 0
    → Solo Obra Social y FSR (aportes + contribuciones)

  Descuentos del trabajador (810xxx, 821xxx):
    Flags: 10000000000 0 0 00 0
    → Descuento puro, sin bases imponibles patronales

6. CONCLUSIONES PARA EL DISEÑO DE ARCA-PLATFORM
=================================================

a) Los códigos ARCA y sus flags son FIJOS a nivel nacional.
   → Deben modelarse como tabla maestra compartida (no por cliente).

b) Los conceptos del contribuyente son PROPIOS de cada empresa.
   → La tabla payroll_concepto debe tener client_id (scope por cliente).

c) Un mismo código ARCA puede mapear a múltiples conceptos del contribuyente.
   → La relación es N:1 (muchos conceptos contribuyente → un código ARCA).

d) El nombre del concepto varía por empresa aunque el código ARCA sea el mismo.
   → El nombre es atributo del concepto del contribuyente, no del código ARCA.

e) Al generar el archivo LSD, el sistema debe:
   1. Tomar los conceptos del cliente (payroll_concepto)
   2. Resolver el código ARCA de cada uno
   3. Escribir el registro con el formato fijo: [cód ARCA][cód contrib][descripción][flags]
   4. Los flags se obtienen de la tabla maestra según el código ARCA
