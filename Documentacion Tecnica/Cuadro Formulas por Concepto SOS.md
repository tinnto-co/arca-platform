# Cuadro de formulas por concepto SOS

Este documento referencia el cuadro operativo de formulas y campos editables por concepto.

## Archivo fuente (canvas)

- `C:\Users\Brian\.cursor\projects\c-Users-Brian-OneDrive-Escritorio-Proyectos\canvases\cuadro-formulas-sos-sueldos.canvas.tsx`

## Contenido del cuadro

El cuadro incluye:

- Siglas y abreviaturas (CN, NR, H, D, R, SAC, HE, Imp.N, OS, ART).
- Glosario de variables/base (SL, S1a9, S1a199, S411a469, H+NR, etc.).
- Prioridad de calculo (orden de aplicacion CN/base/importe/%/clamp).
- Matriz por codigo/rango con:
  - Base de calculo
  - Formula efectiva
  - Impacto contable (Haberes / Descuentos / Retenciones / No remunerativo)
  - Campo UI relacionado (cantidad, %, Imp.N, importe, min, max, etc.)
- Notas operativas para conceptos criticos (42, 501-504, 511-520, 551-562).
