- Implemented per-screen contextual chat suggestions for the CopilotBottomPanel using `useCopilotChatSuggestions` from `@copilotkit/react-ui`.

  - Go to `/vencimientos` → 3 suggestions about próximos 7 días, agrupar por impuesto, total estimado.
  - Go to a route without specific match (e.g. `/admin`) → no suggestions chips appear (component registers `available: 'disabled'`).
  - Toggle `ai_agent` off in `/admin` (if available) → CopilotKit subtree unmounts entirely; no console errors related to suggestions.

- **Learnings for future iterations:**
  - The `useCopilotChatSuggestions` hook signature is `(config, dependencies)`. Pass `[instructions]` as the dependency array so suggestions re-register when the active route changes — otherwise the model keeps the previous screen's hint.
  - Spreading instructions to `''` and `available: 'disabled'` on default routes is cleaner than conditionally calling the hook — React rule-of-hooks forbids conditional calls. Always invoke; toggle via `available`.
  - Pattern `/^\/clients\/[^/]+/` matches `/clients/:id` AND any nested subroute under it; check this BEFORE the literal `/clients` match to avoid matching the list page on detail URLs.
  - All screen-specific instructions assume the corresponding `useCopilotReadable` is mounted on that page (already done in prior runs for sueldos, clients-table, client-detail-page, notifications-view). If you add new screens later, add the readable BEFORE adding suggestions for that screen.
