## Codebase Patterns
- Migration scripts live in `src/scripts/` and use `ADD COLUMN IF NOT EXISTS` via `db.execute(sql.raw(...))` for idempotent migrations
- Pre-existing TS errors exist in some `src/scripts/` files (map-import-empleados, report-unmatched, etc.) — these are not related to our changes
- TypeScript check: `bunx tsc --noEmit` (no `typecheck` script in package.json)
- Migration pattern requires `DATABASE_URL` env var and uses `dotenv/config` import
